# GeoHum_PWTT
Damage probability based on S1 based on the PWTT methodology constrained with at choice different land use like ESA landcover ,GHSL
PWTT showed added value for large territory and as well when high resolution of data might lack. it is as well interesting to have such type of 2 steps approach with a proxa map based on the probability before to engage an analysis with high resolution if needed. Tests comparisons and use were done in South Lebanon in the spring 2026.  Comparison on some localities like Deir Seidan, Bint Jbeil or sour show good results already demonstrated by Olie Ballinger
